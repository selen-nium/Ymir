# Lens validation, 15 November 2026

This update integrates the reviewed Stoa Lens runtime, compact count scope,
source-bound evidence, document intake, durable jobs and editable reviews.
Trained classes retain D-FINE routing; Kimi remains the untrained-class
specialist. The explicit atomic Kimi diagnostic is separate from production
routing. Neither a lower count gate nor a new detector threshold was introduced.

The isolated release snapshot passes 114 backend tests. Frontend ESLint,
TypeScript, 44 unit tests and the production build pass. The upstream Lens suite
passes 97 tests. A separate Chromium workflow audit exercised Ask, reconnect,
review revisions, PDF import, featured examples, window editing and a 33MP image
upload on isolated fixture services. Its deterministic responses establish
workflow behavior rather than live inference accuracy or provider readiness.

The frozen compact atomic-Kimi test reused all eight historical object cases.
It returned five answers: four exact official counts and one overcount; three
cases required review. There were no service failures. The earlier initialization
attempt had eight missing-asset failures before inference and zero paid calls;
those receipts remain archived separately. The completed compact run cost
US$0.610570, with no unresolved charges at its final snapshot. Median trajectory
time was 188.84 seconds; nearest-rank p90 was 556.42 seconds, including waits.

The archived DeepSeek plus Kimi study achieved 5/8 correct and answered 7/8 on
the same source hashes and official count references. Its tool/prompt contract
differs, and two correct cases received OCR results. Dedicated OCR is disabled
in the new product. The compact result therefore does not establish an accuracy
improvement or isolate the effect of contract size or OCR. No review case was
rerun to improve the score.

The broader production-routing study uses 64 frozen Junction count questions,
including bilingual pairs and 37 visual families. All are exposed diagnostics.
Four residential-unit questions lack a supported bound object taxonomy and stay
in the planned denominator. Official object boxes are unavailable; no official
box precision/recall is claimed. This count subset does not cover Junction's
area, volume, length or text tasks.

The seven Hardprobs attempts and three real Ymir API workflow requests are
reported separately from that count study. Hardprobs has no supplied reference
answers. Printed areas remain readings; source-calibrated raster areas remain
estimates. Unsupported slab partitions, pipe connectivity and continuous
baseboard deductions cannot be treated as verified measurements.

Full experiment receipts, source hashes, model journals, offline metrics and
native-pixel galleries remain in the Stoa workspace. No benchmark references,
credentials, experiment ledger or private model checkpoints are bundled with
this release. Backend cloud deployment remains a separate manual workflow.
